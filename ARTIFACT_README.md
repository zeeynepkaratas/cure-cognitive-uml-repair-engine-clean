# CURE research artifact

Read README.md, docs/evaluation-protocol-v4.md and docs/revision-report.md.
The manuscript is outside this source-code revision.

For anonymous review export tracked files without .git, local environments,
credentials, caches, docs/archive_internal/, or historical *_not_run.md notices.
Scan the export for contributor identities and absolute local paths, then upload
it to an independent anonymous service. The public GitHub account and history
are not anonymous. A configured anonymous URL is only a placeholder until an
export has actually been uploaded.

RESULTS_MANIFEST_ORIGINAL.json and the redaction verification preserve historical
evidence. Do not pool older pipeline results as repetitions of the v4 system.
New raw measurements belong to backend/evaluation/results_v4/<run_id>/ with
protocol commit, environment, exact model metadata, traces and output hashes.
Supplementary files publish all prompts, rule descriptions, gold models and splits.
Only explicitly completed runs in the revision report were executed. Fake-LLM
tests do not establish experimental performance. Paid model runs require budget
limits and a local key. All pending conditions must remain clearly marked pending.
