## Prioritized unresolved issues

1. **OPEN — semantic false acceptance.** C7 M11_2 retains WeatherStation, returns Critic-valid and accepts in 5/5 repeats. Class F1 is 8/9, not 1. The parser sees the extra class correctly; project rules/compiler accept it because it is syntactically legal. The Critic/rubric/grounding and acceptance policy fail to exclude it. The trace does not identify a unique causal contribution of retrieval. Frozen regression tests document the failure without tuning. [Failure analysis](SEMANTIC_FAILURES.md).
2. **OPEN — independent gold and generalization.** All 30 semantic scenarios share one four-class/four-edge graph template. SRS and gold are co-constructed; expert annotations, representative external models and source-disjoint validation are **BULUNAMADI**. A two-annotator protocol and new sealed v5 plan are specified, not executed.
3. **PARTIAL — statistical inference and C2 freeze qualification.** Case-level Wilson/McNemar do not adjust for scenario/source dependence. Semantic paired bootstrap/Wilcoxon use scenario means; original between-condition Wilcoxon p-values are unadjusted. Audit-only Holm sensitivity is retrospective. C2's first shared result is 49/50, revised 50/50 is post-test exploratory. Both are retained. Every closure table labels revised C2 exploratory; frozen publication input tables lack that label in every row and are deliberately left unchanged. Publication owner must carry the qualification into every future manuscript table.
4. **OPEN — anonymity.** Export tools and byte/PDF scans cannot make public history or retained commit/dataset breadcrumbs anonymous. Hosting independent of identifying accounts and a human contextual review are still required. [Scan](ANONYMITY_SCAN.json); no upload performed.
5. **OPEN — historical PURE reduction.** Official v1 XML archive has 18 usable files and produces 7,017 new rows / 7,162 index chunks, not the historical 7,219 statements. The 34,268-to-7,219 reduction is not reproduced. All P cases come from one CCTNS document, and P02 drops an opt-in qualifier.
6. **PARTIAL — runtime security, not production certification.** The original research renderer demonstrably reads an auditor-owned local include under default LEGACY security. New `v5-api-sandbox` containment is API-only: SANDBOX JVM, pinned JAR, input/body/line/class limits, memory/timeout/concurrency, credential-free child environment and SVG filtering. Legacy HTTP is disabled by default. The trusted research runtime remains unchanged. Authentication, tenant-specific budgets/rate limits, request cancellation/load tests, OS isolation and log retention/privacy controls remain OPEN. No sensitive host file or network target was probed.
7. **OPEN — parser coverage.** Real PlantUML compiles a note containing `class Ghost`, but the frozen parser wrongly counts Ghost as a class; it omits a valid compound `*-->` edge. These are now fixture regressions and documented scope boundaries. They are not silently fixed after held-out evaluation. Typed-edge categories are an operational schema, not full UML semantics.
8. **NOT TESTABLE — Docker and full external replication.** Docker executable and independent expert/hosting artifacts are BULUNAMADI. Current JVM/HTTP checks and a clean Python install are not evidence of a Docker build or future provider availability.
